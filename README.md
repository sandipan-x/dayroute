# DayRoute

Free trip day planner: add your sights with durations and auto-balance them into realistic days with time budgets. Copy, print, no signup.

## Features
- Auto-balance stops into days with per-day time-budget meters
- Move stops between days, reorder, and fine-tune by hand
- Trip presets, copy/print itinerary and autosave in the browser
